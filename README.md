# 🧠 NeuroAnatomy 3D

**High-fidelity interactive 3D anatomical atlas with raycasting selection, dual GLTF/procedural models, anatomical layer filtering, and clinical RAG assistant (ChromaDB + Gemini/OpenAI/Mock).**

> ⚠️ **MEDICAL DISCLAIMER** — NeuroAnatomy 3D is designed exclusively for **educational, academic, scientific dissemination, and biomechanical training** purposes.
> - Information generated by the RAG engine and LLMs **does NOT constitute medical advice, clinical diagnosis, or therapeutic recommendation**.
> - No interaction in this application should substitute the clinical judgment of a qualified physician or healthcare professional.
> - For any ailment, symptom, or emergency, seek immediate medical attention from a licensed specialist.

---

## ✨ Features

| Feature | Description |
|---------|-------------|
| 🧬 **Interactive 3D Atlas** | Three.js + Angular 18 Standalone Components, cinematic 3-point lighting, dark medical studio background (`#0b1120`) |
| 🎯 **Precision Raycasting** | Mouse hover → emissive highlight, click → select + focal zoom, anatomical part identification |
| 🔄 **Dual Model System** | Auto-load GLTF (`/assets/models/human_anatomy.glb`) with instant fallback to articulated procedural mannequin grouped by anatomical layers |
| 🎚️ **Layer Filtering** | Toggle **Skeletal**, **Muscular**, **Nervous** systems independently or **All**; **Wireframe** mode for structural analysis |
| 📚 **Clinical RAG Assistant** | ChromaDB vector store + LangChain, real-time semantic indexing of anatomical/biomechanical corpus |
| 🤖 **Multi-Provider LLM** | Google Gemini API, OpenAI API, **Mock mode (100% offline, zero cost, no API keys required)** |
| 📖 **Sourced Responses** | Structured answers with bibliographic citations and correlated anatomical structures |
| ⚡ **Reactive Architecture** | Angular 18+ Signals, Tailwind CSS clinical dark theme, FastAPI async backend, Pydantic v2 |
| 🐳 **Docker Ready** | Single `docker compose up --build` spins up frontend (Nginx) + backend + ChromaDB persistence |

## 🚀 Quick Start

### Option 1: Docker Compose (Recommended)
```bash
# Clone & enter
git clone https://github.com/CryptonDevAlex/neuroanatomy-3d.git
cd neuroanatomy-3d

# Launch all services (frontend + backend + ChromaDB persistence)
docker compose up --build
```

| Service | URL |
|---------|-----|
| **Frontend (Angular + Nginx)** | http://localhost:4200 |
| **Backend API (FastAPI + Swagger)** | http://localhost:8000/docs |
| **Health Check** | http://localhost:8000/api/health |

---

### Option 2: Local Development

#### 1. Backend
```bash
cd backend

# Virtual environment
python -m venv .venv
# Windows PowerShell:
.venv\Scripts\Activate.ps1
# Linux/macOS:
# source .venv/bin/activate

# Dependencies
pip install -r requirements.txt

# Environment (defaults to LLM_PROVIDER=mock — works 100% offline)
cp .env.example .env
# Edit .env if you want Gemini/OpenAI

# Run with hot reload
uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload
```

#### 2. Frontend
```bash
cd frontend

# Dependencies
npm install

# Dev server
npm start
# or: npx ng serve --port 4200
```

**Open:** http://localhost:4200

## ⚙️ Configuration (`backend/.env`)

| Variable | Options | Default | Description |
|----------|---------|---------|-------------|
| `LLM_PROVIDER` | `mock` \| `gemini` \| `openai` | `mock` | **Mock mode = fully offline, zero cost** |
| `GEMINI_API_KEY` | `AIzaSy...` | — | Google AI Studio key |
| `OPENAI_API_KEY` | `sk-...` | — | OpenAI API key |
| `CHROMA_PERSIST_DIR` | `./chroma_db` | `./chroma_db` | Vector store persistence path |

> **Tip:** With `LLM_PROVIDER=mock`, the system runs 100% locally using ChromaDB semantic retrieval + deterministic synthesizer over the included medical documents. No API keys, no network calls, no costs.
